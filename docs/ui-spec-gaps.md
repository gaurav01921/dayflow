## Remaining Gaps

### 1. Salary Info tab visibility

| | |
|---|---|
| **Spec** | Salary Info tab should only be visible to Admin/HR |
| **Current** | Salary Info tab visible to ALL users (no role check) |
| **Status** | ❌ NOT IMPLEMENTED |
| **Owner** | M3/M4 (`src/pages/employee/profile-page.tsx` lines 386-389) |
| **Impact** | Regular employees can see salary breakdowns |

The `TabsTrigger value="salary"` is rendered unconditionally. Should be wrapped in `{isManagerRole(currentUser?.role) ? ... : null}`.

---

### 2. Login ID format mismatch

| | |
|---|---|
| **Spec** | `OI` + first2(first) + first2(last) + year + serial → `OIJODO20220001` |
| **Current** | first3(company) + first1(first) + first1(last) + year + serial → `ODIJD20260001` |
| **Status** | ⚠️ FORMAT MISMATCH |
| **Owner** | M4 (`src/mocks/mockApi.ts` lines 169-176) |
| **Decision needed** | Which format is authoritative? |

### 3. Salary component calculations — not formula-driven

| | |
|---|---|
| **Spec** | Basic = 50% Wage, HRA = 50% Basic, Bonus = 8.33% Basic, LTA = 8.33% Basic, Fixed = Wage − all |
| **Current** | Hardcoded display constants (200, 300, 150, 150) |
| **Status** | ❌ NOT IMPLEMENTED |
| **Owner** | M4/M2 (`src/pages/employee/profile-page.tsx` lines 255-262) |

```typescript
// Current (hardcoded):
const standardAllowance = 200
const performanceBonus = 300
const lta = 150
const fixedAllowance = 150

// Required (formula-driven):
const basicSalary = Math.round(monthlyWage * 0.5)
const hra = Math.round(basicSalary * 0.5)
const performanceBonus = Math.round(basicSalary * 0.0833)
const lta = Math.round(basicSalary * 0.0833)
const fixedAllowance = monthlyWage - basicSalary - hra - 4167 - performanceBonus - lta
```
